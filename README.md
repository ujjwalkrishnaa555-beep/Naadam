# Naadam
Free royalty-free music streaming website.

What it is
- A simple web app to browse and play royalty-free music.

Features
- Browser-based music player
- Free royalty-free tracks
- Responsive UI

How to run
1. Clone the repo:
   git clone https://github.com/ujjwalkrishnaa555-beep/Naadam.git
   cd Naadam

2. If it's a static site:
   - Open index.html in a browser

3. If it uses Node/React/Vite:
   npm install
   npm start
   # or the project's start command

Contributing
- Keep audio assets in /assets or /public.
- Add playlists as JSON in /data or as JS modules in /src.
- Open issues or PRs for changes.
